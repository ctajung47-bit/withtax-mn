## 3. 웹 앱으로 배포
1. 오른쪽 위 **배포** → **새 배포**
2. 톱니 → 유형 **웹 앱**
3. 설명: `v1` / **실행 사용자: 나** / **액세스 권한: 모든 사용자**
4. **배포** → 나오는 **웹 앱 URL** 복사 (`https://script.google.com/macros/s/…/exec`)

## 4. 홈페이지에 연결
`config.js` 의 빈 문자열에 URL을 넣고 저장 → GitHub에 푸시 (Claude에게 URL만 주면 됨)
```js
window.WITHTAX_ENDPOINT='https://script.google.com/macros/s/…/exec';
```
연결 전까지 접수 페이지는 테스트 모드로 동작합니다 (화면에 "서버 미연결" 표시, 저장 안 됨).
